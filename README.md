# 🖥️ TechWorld - Electronics & Gadgets

TechWorld is a responsive e-commerce website for browsing and purchasing electronic products and gadgets.

## 🌐 Live Website

Add your GitHub Pages link here:

https://yourusername.github.io/TechWorld/

## 📌 Features

- 🏠 Home page
- 🛍️ Product listing
- 🔍 Product search
- 📂 Category filtering
- 🏷️ Brand filtering
- 👁️ Product details page
- 🛒 Shopping cart
- ➕ Increase/decrease product quantity
- ❌ Remove products from cart
- ❤️ Wishlist
- ⭐ Customer reviews and ratings
- 💳 Checkout page
- 📦 Order history
- 🚚 Order tracking
- 🔢 Automatic Order ID generation
- 📱 Responsive design
- 💾 Local Storage for cart, wishlist, reviews and orders

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Local Storage
- GitHub Pages
